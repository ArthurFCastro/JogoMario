Jogo Mario

Descrição

Projeto de desenvolvimento de um jogo inspirado no universo do Mario, desenvolvido como atividade acadêmica para colocar em prática conceitos de desenvolvimento web, Git e GitHub.

Objetivo

Desenvolver um jogo simples utilizando tecnologias web, aplicando conceitos de organização de projetos, controle de versões, desenvolvimento colaborativo e documentação.

Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

Instalação

Clone o repositório e acesse a pasta do projeto:

git clone https://github.com/ArthurFCastro/JogoMario.git
cd JogoMario

Execução

Entre na pasta frontend e abra o arquivo index.html em um navegador.

frontend/index.html

O jogo utiliza HTML, CSS e JavaScript, portanto não é necessário instalar dependências para executar a versão atual.

Controle de versões

O projeto utiliza Git para controle de versões e GitHub para hospedagem do repositório.

As principais branches utilizadas são:

* main — versão principal do projeto.
* dev — branch utilizada durante o desenvolvimento.
